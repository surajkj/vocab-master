## Description

Vocab Master is a React-based application designed to help users improve their vocabulary.

## Prerequisites

- Node.js (v16 or higher recommended)
- npm (comes with Node.js)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/snpm startnpm starturajkj/vocab-master.git
   ```
   
2. Navigate to the project directory:
   ```bash
    cd vocab-master
    ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm start
   ```
5. Build
   To build the project for production, run:
```bash
npm run build
```
